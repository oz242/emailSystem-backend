# 📧 MailBlast — Bulk Email Sender

A production-ready Bulk Email Sender application built with **React + Vite** (frontend) and **Node.js + Express** (backend). Send personalized bulk emails from Excel/CSV files with SMTP rotation, real-time monitoring, and a beautiful dark/light UI.

---

## ✨ Features

- 📂 **Excel/CSV Import** — Drag-and-drop upload with column auto-detection and mapping
- ✍️ **Dynamic Personalization** — `{{name}}`, `{{email}}` and any custom column as template variables
- 📤 **Bulk Email Sending** — Sequential sending with configurable inter-email delay
- 🔄 **SMTP Rotation** — Add multiple SMTP accounts and automatically rotate between them
- ▶️ **Full Queue Controls** — Start, Pause, Resume, Stop any campaign instantly
- 🔁 **Retry Failed** — One-click retry for all failed recipients
- 📊 **Real-time Dashboard** — Live progress bar, stats (sent/failed/pending), and terminal-style log console
- 📋 **Campaign History** — Browse all past campaigns with expandable log views
- 📥 **Export Failed CSV** — Download failed recipients to re-import and retry
- 🌙 **Dark / Light Mode** — Toggle with persisted preference
- 📎 **Multiple Attachments** — Attach files to every email in the campaign
- 🤖 **Quick Templates** — 5 pre-built email templates (Welcome, Promo, Invite, Follow-up, Notice)
- ⚡ **Live Preview** — See exactly how each recipient's personalized email will look before sending

## 🚀 Quick Start

### Prerequisites
- **Node.js** v18+ (download from https://nodejs.org)
- **npm** v9+
- A **Gmail Account** with an App Password (see below)

### 1. Clone / Navigate to project

```bash
cd emailSystem
```

### 2. Setup Backend

```bash
cd backend
npm install
```

Create `.env` file (already created with defaults):
```env
PORT=5000
FRONTEND_URL=http://localhost:5173
```

Start backend:
```bash
npm run dev
```
Backend runs on **http://localhost:5000**

### 3. Setup Frontend

Open a new terminal:
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on **http://localhost:5173**

### 4. Open in Browser

Navigate to **http://localhost:5173**

## 📧 Gmail App Password Setup

Gmail requires App Passwords when 2-Step Verification is enabled:

1. Go to your [Google Account](https://myaccount.google.com)
2. Navigate to **Security** → **2-Step Verification** → scroll down
3. Click **App passwords**
4. Select app: **Mail**, device: **Other** (name it "MailBlast")
5. Copy the 16-character generated password
6. Use that password in MailBlast's SMTP settings (NOT your regular Gmail password)

**SMTP Settings for Gmail:**
| Field | Value |
|:---|:---|
| Host | smtp.gmail.com |
| Port | 587 |
| Secure | OFF (uses STARTTLS) |
| Username | yourname@gmail.com |
| Password | Your 16-char App Password |

## 🗺️ Usage Guide

### Step 1: Add SMTP Account
1. Go to **SMTP Settings** in the sidebar
2. Click a preset (Gmail, Outlook, etc.) or enter custom details
3. Enter your email and App Password
4. Click **Save Profile**
5. Click **Test** to verify the connection

### Step 2: Import Recipients
1. Go to **Import Sheet**
2. Drag & drop your `.xlsx`, `.xls`, or `.csv` file
3. Map the **Email Column** and **Name Column** to your file's headers
4. Verify the preview table — invalid emails are highlighted
5. Click **Proceed to Compose**

### Step 3: Compose Email
1. Go to **Compose**
2. Enter a **Campaign Name** and set a **Delay** between sends
3. Write your **Subject** and **Body** — click column tags to insert `{{variables}}`
4. Toggle **Show Preview** to see personalized emails per recipient
5. Optionally attach files
6. Click **Create & Send Campaign** — you'll be redirected to Dashboard

### Step 4: Monitor & Control
1. The **Dashboard** shows real-time progress with live logs
2. Use **Pause / Resume / Stop** to control execution
3. Use **Retry Failed** after the campaign finishes to resend failures
4. **Export CSV** downloads all failed recipients for review

## 🔒 Security Notes

- **Passwords are never logged** or returned in API responses (obfuscated)
- **Rate limiting** prevents API abuse (200 requests/15 min, 10 sends/5 min)
- **Input validation** on all endpoints
- **Environment variables** for all sensitive config
- **No passwords stored in frontend state** — only used transiently by backend

## 🐛 Troubleshooting

**"Authentication failed" SMTP error**
→ Make sure you're using an **App Password**, not your regular Gmail password. Enable 2-Step Verification first.

**"Less secure app access" error**
→ Use App Passwords instead. Google has deprecated Less Secure App Access.

**Backend not starting**
→ Check that port 5000 is free: `netstat -ano | findstr :5000`

**Frontend not connecting to backend**
→ Ensure backend is running on port 5000. The Vite proxy forwards `/api` requests automatically.

**Emails going to spam**
→ Add SPF/DKIM records for your domain. Increase delay between sends. Warm up new SMTP accounts gradually.
